# Indexing

:::warning Experimental
This feature is experimental and under active development. The output and command-line options may change in future releases.
:::

Pyrefly can generate a [SCIP](https://github.com/scip-code/scip) index for code-navigation
tools that consume this format. The index records definitions, references, hover documentation,
and implementation relationships.

From the project root, run:

```sh
pyrefly check --report-scip index.scip
```

Pyrefly uses its normal configuration and import resolution. The index contains documents for the files being checked, with paths relative to the
current directory. Use `--relative-to path/to/project` to select a different project root.
In either case, only files under the project root become documents.

Type errors are still reported normally and can make the command return a nonzero exit status
even when it writes an index.

Symbols in statically unreachable branches (based on platform/Python version or the `@no_type_check` decorator) are not analyzed.

## Package identity

The project's symbols use the package name and version from `[project]` in the root's
`pyproject.toml`, falling back to `[tool.poetry]`. Override either value explicitly:

```sh
pyrefly check --report-scip index.scip \
  --report-scip-project-name my-package \
  --report-scip-project-version 1.0.0
```

External package identities come from installed distribution metadata, and bundled standard-library stubs use the Python version
configured for the project.

## Test code

Occurrences in test code get the SCIP `Test` role. Test code is:

- every `.py` file that pytest collects tests from, by the `python_files` setting in the pytest
  configuration file of the project root (by default `test_*.py` and `*_test.py`), and every
  `conftest.py`;
- every class that derives from `unittest.TestCase`, wherever it is defined.

## Compatibility

:::tip
If your tools need [LSIF](https://microsoft.github.io/language-server-protocol/specifications/lsif/0.6.0/specification/)
instead, convert the index with the [`scip` CLI](https://github.com/scip-code/scip):

```sh
scip convert --from index.scip --to dump.lsif
```

:::

Pyrefly's output is close to Sourcegraph's [scip-python](https://github.com/sourcegraph/scip-python)
indexer and uses the same symbol naming format, but outputs are not identical.
